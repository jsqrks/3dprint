Colle
Textured PEI : non requise · Engineering Plate : obligatoire (pages des plaques Bambu)
Chambre
≤ 45 °C · plateau > 45 °C : porte ouverte ou capot vitré retiré (wiki)
Séchage
Non indiqué pour ce filament · sécheur GEEETECH D1 : PLA 45–50 °C · 6–8 h → 50 °C · 8 h au plus · en AMS : mode rotation (wiki)
Hotend
Standard · Bambu déconseille ses hotends acier trempé 0,6 / 0,8 mm pour son PLA Silk+ (page boutique Bambu)
Alimentation
AMS 2 Pro ou AMS HT · pas de RFID : régler le type PLA à la main
Track Switch
PLA Silk : ⚠️ déconseillé ; Bambu conseille de l'éviter avec le Track Switch

Règles d'usage

  • Groupe basse température H2C : jamais dans le même travail qu'un filament haute température (ABS, ASA, PC, PA…), chambre ≤ 45 °C (guide H2C)
  • Imprimer une tour de température pour chaque couleur (wiki GEEETECH)
